1- Modern responsive design
2- using flexbox and grid
3- two Radio buttons to choose between search by username or organization name
4- Text field to enter the username or organization name
5- Button to search
6- very simple Github search api
7- using async/await
8- using fetch api
9- using modules
10- using template literals
11- using arrow functions
12- using destructuring
13- using spread operator
14- In case of choosing username radio button, the search api will be https://api.github.com/users/{username}/repos
15- In case of choosing organization radio button, the search api will be https://api.github.com/orgs/{organization}/repos
16- The output will be a list of repositories for the given username or organization
17- Each repository will have a name, description, and a link to the repository
18- once the user clicks any repository name, it will open the repository in a new tab
19- users can use both keyboard and mouse to navigate through the radio buttons, text field, search button, and repositories.
